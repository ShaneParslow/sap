# Vision

sap starts from a question about the future rather than a technical itch: if AI makes writing software nearly free, what foundations decide whether computing ends up owner-controlled or locked down, and which of them can be built now? The design chat that seeded this wiki began there and worked down the stack. The technical areas of the wiki are the answer it arrived at; this area records the reasons, so later design choices can be checked against them.
